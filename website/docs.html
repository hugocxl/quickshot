Using Quickshot

Install, capture, paste and troubleshoot

  • Version {{version}}
  • macOS 14 or later

Quickshot lives in the menu bar. Press left Command and right Command together, and it saves the display under your pointer as a PNG and copies the file’s absolute path to your clipboard. It captures a whole display. It does not offer region selection or annotation.

Install

Quickshot needs macOS 14 Sonoma or later and runs natively on Apple silicon and Intel.

  1. Download the universal ZIP from the Releases page.
  2. Unzip it and move Quickshot.app to Applications.
  3. Open Quickshot. A camera viewfinder icon appears in the menu bar. There is no Dock icon.

Each release is signed with a Developer ID, notarized by Apple and published with a SHA-256 checksum. Downloads appear on the Releases page once the first signed release is published. Until then, you can build Quickshot from source.

Allow two permissions

Open Permissions & Setup… from the menu. It also appears on its own when access is missing, and explains what each permission enables before macOS asks.

  • Input Monitoring lets Quickshot recognize the two Command keys from any app.
  • Screen Recording lets it take the screenshot.

Click Allow beside each one. The setup window updates as permissions change. Relaunch Quickshot if macOS asks. You can also close the window or choose Set Up Later.

Take a screenshot

Move your pointer to the display you want, then press left Command and right Command together, in either order. Quickshot takes one screenshot per press. Release both keys before the next one.

Ordinary shortcuts such as Command-C cancel the gesture, so copying and pasting never takes a screenshot by accident. You can also choose Take Screenshot from the menu.

Quickshot saves the whole display at its native resolution, with every window on it, and leaves out its own preview and setup windows. It works the same in full-screen apps and on every Space.

Paste the path

The clipboard holds the path of the PNG, not the image itself. Paste it into your terminal, a coding agent or any other tool that accepts local image paths. The path is ready as soon as the screenshot is saved. Every file name has a timestamp and a unique identifier, so captures never overwrite one another.

The preview

A soft flash and the macOS shutter sound confirm each capture, and the screenshot shrinks into a small preview in the bottom-right corner of that display. It never takes keyboard focus, so you keep typing where you were.

  • The preview stays for three seconds. Hover over it to keep it on screen.
  • Click it to open the PNG, or use its close button to dismiss it.
  • With Reduce Motion on, the preview simply fades in, without the flash or the flight.
  • The shutter sound follows your Mac’s volume and mute.
  • VoiceOver announces that the path was copied.

Where captures go

Choose Save Files To in the menu. Quickshot remembers your choice, and Desktop is the default.

DestinationFolderKept
DesktopYour DesktopUntil you delete them
tmp (auto-delete after 24 hours)A Quickshot folder in the macOS temporary directory24 hours, removed at launch and hourly while running

macOS can also clear temporary files sooner, so a path in tmp is not permanent. Changing the destination leaves existing captures where they are. Show Screenshots in Finder opens the current folder.

Privacy

Screenshots stay on your Mac. Quickshot has no account and no upload service. Input Monitoring is only used to recognize the two Command keys: Quickshot does not read or record your typing, and every key press passes through unchanged.

Cleanup only removes expired Quickshot screenshots from its temporary folder. It never touches other files or your Desktop captures.

Troubleshooting

Open Permissions & Setup… to check access. Its Already enabled, but not working? section helps when a permission looks on but has no effect, and Show This App in Finder points to the exact app to allow.

  • If the shortcut stops responding, choose Retry Shortcut from the menu.
  • Secure Keyboard Entry, including Terminal’s optional mode, and password fields can pause global shortcuts. The menu shows when this happens, and the shortcut resumes once they end.
  • Use Take Screenshot to check capture on its own, apart from the keyboard shortcut.

For a bug report, Copy Permission Diagnostics gathers useful details. Review them before sharing in a GitHub issue.

Build from source

Open Quickshot.xcodeproj in Xcode with Swift 6 support and select your development team under Signing & Capabilities, or build from the terminal.

git clone https://github.com/hugocxl/quickshot.git
cd quickshot
scripts/build.sh

scripts/validate.sh runs an isolated build, the regression tests and the app bundle checks. The development notes describe the architecture and manual checks, and RELEASE.md covers signing and publishing.
